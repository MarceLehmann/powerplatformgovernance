## AdminHelper: governance flows you install yourself

AdminHelper is a set of Power Automate flows that look at your tenant for you and report by e-mail: which environments, apps, flows and Copilot Studio agents exist, which ones have lost their owner, where sharing or connectors are too open. Anything that changes something runs as a dry run first and only reports what it would do.
