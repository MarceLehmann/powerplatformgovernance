## TL;DR

A Copilot Studio agent followed an instruction to reject questions unrelated to a training course, but later answered one after a matching custom MCP tool returned numbers. The author infers that MCP tools may take priority over agent instructions, allowing tool responses to continue a conversation despite configured constraints and creating unpredictable behaviour.

{% include curated-attribution.html %}

## Governance takeaway

Admins/CoE should test every Copilot Studio agent instruction together with its configured tools, especially custom MCP servers, because a matching tool may change the agent’s response path. Security/Compliance should treat instruction-only restrictions as insufficient control until tool invocation and response handling have been tested, because the example shows an agent continuing an unrelated conversation after an MCP response.
