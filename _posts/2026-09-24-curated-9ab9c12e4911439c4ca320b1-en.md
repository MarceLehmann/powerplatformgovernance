## TL;DR

When a cloud flow is no longer in a solution but Export &gt; Package (.zip) remains hidden, open My flows, change the details URL suffix to /export, configure Create as new or Update, and download the package. Only owners or co-owners can export; third-party cookies are required.

## Governance takeaway

Makers stuck with a flow that's already been removed from a solution can use the /export URL trick to pull it out via Create as new or Update, but only if they're already an owner or co-owner — it grants no access beyond that. Admins/CoE should treat /export as a one-off rescue, not a supported ALM path, and standardize on Dataverse solutions for anything that needs to move repeatably across environments. Security/Compliance should flag any process that leans on /export as a documentation gap worth closing, since an undocumented URL pattern can change or disappear without notice.
