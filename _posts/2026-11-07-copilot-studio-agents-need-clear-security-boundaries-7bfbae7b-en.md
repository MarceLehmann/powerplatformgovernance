## TL;DR

Copilot Studio agents connect AI to data and actions, so admins and makers should set security boundaries, review data access and connectors, verify authentication and sharing, and assess what each agent can reach to reduce data exposure while keeping makers productive and safe.

{% include curated-attribution.html %}

## Governance takeaway

- Makers: Review which data and actions each Copilot Studio agent can reach so its boundaries are understood before use.
- Admins/CoE: Set agent boundaries and examine connectors, authentication and sharing to keep makers productive and safe.
- Security/Compliance: Assess reachable resources and exposure risk because agent security boundaries become part of the wider architecture.
