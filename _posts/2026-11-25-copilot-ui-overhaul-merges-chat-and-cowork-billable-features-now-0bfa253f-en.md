## TL;DR

Microsoft&\#39;s Copilot app UI in Frontier replaces separate Chat and Cowork tabs with a Home tab, moves the mode selector into the chat box, and adds Plugins, Automations, Workspaces and personal Projects. The merged interface makes it far easier to trigger usage-based billable Cowork features by accident; scheduled Chat prompts remain under the chat&\#39;s three-dot menu, not Automations.

## Governance takeaway

- Makers: Remember the chat box keeps your last used mode, so check whether Cowork is selected before starting work, since Cowork actions can incur usage-based charges.
- Admins/CoE: Brief adoption leads on the new Home, Plugins, Automations and Projects layout and remind users that scheduled Cowork tasks are billable while scheduled Chat prompts are managed separately in the chat menu.
- Leadership/Business: If Cowork billing spikes after rollout, ask whether new spend reflects valuable use cases or users confused about which options are billed.
