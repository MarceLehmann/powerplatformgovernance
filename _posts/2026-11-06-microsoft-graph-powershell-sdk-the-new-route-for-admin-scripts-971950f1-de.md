## TL;DR

Das Microsoft Graph PowerShell SDK bietet einen zentralen Microsoft-Graph-Zugang für die Administration. Es behandelt Anmeldung und Berechtigungen, das Auflisten von Benutzern, Teams-Nachrichten sowie typische Fehler und Grenzen und ersetzt zwei veraltete Administrationsmodule, darunter den bisherigen Azure-AD-Modulpfad.

{% include curated-attribution.html %}

## Bedeutung für Governance

- Admins/CoE: Nutzt das Microsoft Graph PowerShell SDK als Ersatz für die zwei veralteten Administrationsmodule und klärt Anmeldung sowie Berechtigungen vor der Ausführung.
- Security/Compliance: Prüft die Berechtigungen bei Graph-PowerShell-Aufgaben, weil die Quelle Berechtigungen, typische Fehler und Grenzen als wichtige betriebliche Punkte nennt.
- Leadership/Business: Berücksichtigt, dass Portalverwaltung und PowerShell-Automatisierung über dieselbe Microsoft-Graph-Ebene verbunden sind, damit die Rolle des SDK neben Azure, Portal und Graph Explorer klar bleibt.
