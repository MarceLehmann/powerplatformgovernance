## TL;DR

Agent 365, included in Microsoft 365 E7, assesses individual agent risk using identity, data, device, cloud, network and activity signals. Dynamic Agent Permissions and Adaptive Conditional Access adjust access, while Project Perception continuously monitors agents. Availability, rollout, regions and licensing remain unspecified for most announced features.

## Governance takeaway

- Admins/CoE: Check Microsoft Learn for availability, rollout, region and licensing before planning Agent 365 or the Sovereign Control Panel, because most statuses are unspecified.
- Security/Compliance: Map agent permissions, activity monitoring, key custody and access records to current controls, because the announcements address these governance questions with new components.
- Leadership/Business: Treat sovereignty and agent security as validation decisions, not assumed capabilities, because tenant usability still requires administrator review.
