- question: Wie bewertet der SharePoint Admin Agent übermässiges Teilen in OneDrive
    und SharePoint?
  answer: Der SharePoint Admin Agent analysiert Inhalte per natürlicher Sprache, bewertet

  answer: Hero Links verwendet standardmässig einen Link pro Datei oder Ordner. Die
    zugehörigen Berechtigungen lassen sich ändern, ohne eine neue URL zu erstellen.

## TL;DR

OneDrive Copilot kann mehrere Tabellen analysieren, Trends erkennen, Informationen vergleichen und Diagramme erstellen. Der SharePoint Admin Agent bewertet Governance und übermässiges Teilen. Inaktive SharePoint-Dateien lassen sich per Richtlinie archivieren, wobei eine What-if-Analyse die Auswirkungen vor der Aktivierung prüft.

## Bedeutung für Governance

- Admins/CoE: Mit dem SharePoint Admin Agent Sites mit übermässigem Teilen erkennen und Governance-Risiken bewerten.
- Security/Compliance: Berechtigungen, geerbte Zugriffe und weit gefasste Anyone-Links vor einer breiteren Copilot-Nutzung prüfen.
- Leadership/Business: Dokumentstruktur und Zugriffsqualität als Voraussetzung für verlässliche und kontrollierte KI-Ergebnisse behandeln.
