## TL;DR

Existing SharePoint and OneDrive .agent agents continue working until the end of March 2027, then stop during a rollout through mid-April. From mid-November, Create an agent opens Agent Builder instead. Owners can use the SharePoint builder Upgrade button or a Copilot in SharePoint skill to convert agents manually, one agent at a time.

## Governance takeaway

- Makers: Review each existing .agent agent and upgrade only those still used, because Microsoft’s conversion process is manual and agent by agent.
- Admins/CoE: Track the March 2027 retirement and the rollout through mid-April, because existing .agent agents will stop working.
- Leadership/Business: Confirm which agent experiences still provide value, since Agent Builder and Copilot in SharePoint cover capabilities that reduce the former SharePoint UI advantage.
