## TL;DR

Copilot Studio Kit adds Agent Inventory for tenant-wide configuration, feature, licensing and credit visibility; Compliance Hub enforces configured governance thresholds; Test Automation supports multi-turn, adversarial, regression and end-to-end validation across agents.

{% include curated-attribution.html %}

## Governance takeaway

- Makers: Run Agent Review and automated test suites before deployment to catch configuration issues and regressions.
- Admins/CoE: Use Agent Inventory for cross-environment visibility into configurations, features, licensing and credit consumption.
- Security/Compliance: Configure Compliance Hub thresholds and requirements so notifications, remediation workflows or enforcement actions address noncompliant agents.
