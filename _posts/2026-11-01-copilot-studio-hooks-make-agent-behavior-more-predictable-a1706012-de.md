## TL;DR

Copilot Studio Hooks starten einen Workflow, sobald ein festgelegtes Ereignis eintritt. Als Beispiele nennt die Quelle den Beginn eines Gesprächs, die Auswahl eines Tools durch den Agenten und Fehler. Dadurch soll das Verhalten von Agenten vorhersehbarer werden.

{% include curated-attribution.html %}

## Bedeutung für Governance

- Makers: Verknüpft Workflows mit Gesprächsbeginn, Toolauswahl und Fehlern, damit der Agent auf die beschriebenen Ereignisse konsistent reagieren kann.
- Admins/CoE: Nutzt diese Ereignistypen als Prüfpunkte für das Verhalten von Copilot Studio Agenten, weil Hooks laut Quelle die Vorhersehbarkeit verbessern.
